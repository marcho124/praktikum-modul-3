1. HTML5 Audio MP3 / OGG / WAV

Elemen <audio> digunakan untuk memutar file audio di halaman web. Atribut controls menambahkan kontrol pemutar seperti play, pause, dan volume. Elemen <source> memungkinkan browser memilih format audio yang didukung.

Format Audio yang Didukung HTML5:

FormatMedia TypeKeterangan
MP3audio/mpegFormat paling populer, didukung semua browser
OGGaudio/oggDidukung Chrome, Firefox, Opera
WAVaudio/wavDidukung Chrome, Firefox, Safari, Opera

2. HTML5 Video MP4 / WebM / OGG

Elemen <video> digunakan untuk menampilkan video di halaman web. Atribut width dan height sebaiknya selalu disertakan agar halaman tidak berkedip saat video dimuat. Atribut controls menambahkan kontrol pemutar video.

Format Video yang Didukung HTML5:

FormatMedia TypeKeterangan
MP4video/mp4Direkomendasikan YouTube, didukung semua browser
WebMvideo/webmDidukung Chrome, Firefox, Opera
Oggvideo/oggDidukung Chrome, Firefox, Opera

3. YouTube Video IFrame Embed

Cara termudah untuk memutar video di HTML adalah menggunakan YouTube. Kita cukup menggunakan elemen <iframe> dan mengarahkan src ke URL embed YouTube dengan ID video yang diinginkan. Metode <object> dan <embed> sudah deprecated sejak Januari 2015.

Parameter YouTube yang Umum:

ParameterValueFungsi
autoplay0 (default) / 1Video diputar otomatis saat halaman dimuat
loop0 (default) / 1Video diputar berulang terus-menerus
controls0 / 1 (default)Menampilkan atau menyembunyikan kontrol pemutar

💡 Contoh URL dengan parameter: https://www.youtube.com/embed/tgbNymZ7vqY?autoplay=1&loop=1&playlist=tgbNymZ7vqY

4. HTML Geolocation API getCurrentPosition()

Geolocation API digunakan untuk mendapatkan posisi geografis pengguna. Karena ini menyangkut privasi, posisi hanya tersedia jika pengguna menyetujuinya. Method getCurrentPosition() mengembalikan objek koordinat yang berisi latitude, longitude, dan accuracy.

Klik tombol di atas untuk menampilkan koordinat Anda...

Properti yang Dikembalikan:

PropertiKeteranganKetersediaan
coords.latitudeGaris lintang (desimal)Selalu
coords.longitudeGaris bujur (desimal)Selalu
coords.accuracyTingkat akurasi posisi (meter)Selalu
coords.altitudeKetinggian di atas permukaan lautJika tersedia
coords.speedKecepatan (meter/detik)Jika tersedia
timestampWaktu responJika tersedia

5. HTML Drag and Drop API draggable="true"

Drag and Drop API memungkinkan elemen untuk diseret dan dijatuhkan ke area lain. Untuk membuat elemen dapat diseret, atur atribut draggable="true". Event yang digunakan: ondragstart, ondragover, dan ondrop. Method preventDefault() diperlukan agar elemen dapat dijatuhkan.
